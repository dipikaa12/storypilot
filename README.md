# StoryPilot

AI-powered product requirements hub for converting BRDs into user stories, 
Jira tickets, and Confluence pages with persistent workstream context.

## Tech stack
- React 18 + Vite 5
- React Router DOM
- Tailwind CSS v3
- Anthropic API (claude-sonnet-4-6)

## Dev setup
\`\`\`bash
npm install
npm run dev
\`\`\`

## Deployment
Vercel — autodeploys on push to main
